# Environment Setup

## Quick Setup

1. **Copy the example file:**
   ```bash
   cp .env.example .env
   ```

2. **Edit the .env file and add your Anthropic API key:**
   ```bash
   # On macOS/Linux
   nano .env
   
   # Or use any text editor
   ```

3. **Replace the placeholder with your actual API key:**
   ```
   ANTHROPIC_API_KEY=sk-ant-your-actual-key-here
   ```

4. **Save and start Docker:**
   ```bash
   docker-compose -f docker/docker-compose.yml up --build
   ```

## Get Your API Key

1. Go to: https://console.anthropic.com/
2. Sign in or create an account
3. Go to "API Keys" section
4. Create a new key or copy an existing one
5. Paste it into your `.env` file

## Troubleshooting

### Docker doesn't see the API key
- Make sure `.env` file is in the project root directory (same level as `docker/`)
- Make sure there are no spaces around the `=` sign
- Restart Docker: `docker-compose -f docker/docker-compose.yml down && docker-compose -f docker/docker-compose.yml up --build`

### Still getting API key errors
- Check the `.env` file exists: `ls -la .env`
- Check the content: `cat .env` (make sure it shows your key)
- Verify Docker is loading it: `docker-compose -f docker/docker-compose.yml config`
